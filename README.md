📊 Index Risk Calculator (Freemium → Pro)

A fast, clean, and trader-focused index position size calculator designed to help traders manage risk accurately when trading indices like US30, NAS100, S&P 500, and more.

This tool calculates recommended lot size and dollar risk based on your account balance, risk percentage, stop loss, and contract value.

🔗 Live App:
https://index-calculator-app.vercel.app/

🚀 Features (Free)

✅ Account balance input
✅ Risk % calculation
✅ Stop-loss based position sizing
✅ Contract value support
✅ Clean, mobile-friendly UI
✅ Instant results
✅ One-click shareable link

This version is completely free to use and requires no signup.
